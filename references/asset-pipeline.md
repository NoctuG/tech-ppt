# 素材流水线：先锁风格，再批量生图

本文件规定本Skill的**固定制作顺序**中最关键的两段：风格锁定（门禁G1）与素材批量生成（门禁G2）。调用生图模型为页面批量制作素材，是本Skill的核心能力，不因"可编辑PPT里文字是原生的"而省略，也不退化成"每页一张整页图"。

执行前先确认[宿主能力适配](host-capabilities.md)里的生图、参考图输入、透明/抠图三项实际状态；生图不可用时按第七节处理。

## 一、顺序不可调换

```
教学底稿与拆页(page-plan v0)
   ↓
风格锁定  G1：style-spec + 风格样张通过  ← 未通过不得进入下一步
   ↓
素材清单(asset manifest) → 批量生图 → 逐项验收
   ↓
G2：清单内每项有合格文件  ← 未通过不得进入组装
   ↓
版面组装 → 层级动画 → 整册验收
```

常见的两种错序都要避免：**边排版边想起来缺图**（导致全册画风漂移、素材互不呼应），和**先生成全套整页图再试图拆层**（拆不出来，只能当图片贴）。

## 二、G1 风格锁定

### style-spec 必须落到具体值

[风格提取](visual-style.md)说明怎么观察；本节规定锁定时必须写死的字段，缺一项不算锁定：

| 字段 | 写什么 | 不合格的写法 |
|---|---|---|
| 造型与媒介 | 卡通化程度、线条粗细与轻重、上色方式、是否有体积与投影 | "卡通、精美、统一" |
| 色彩系统 | 底色、正文墨色、主色、强调色的**具体色值**与语义分工（对照[版面底版](page-chassis.md)第四节） | "暖色调" |
| 字体系统 | 标题族、正文族的具体字体或替代方案；三级字号的百分比 | "用好看的中文字体" |
| 板材与元件 | 主板形态（纸/卡/框）、边缘处理、标题牌、小标签、结论条、箭头的共同形状规则 | "按需要加卡片" |
| 角色设定 | 若有复现角色：身份、年龄、服装、配色、面部特征；无角色时明确写"无复现角色" | 留空 |
| 底图策略 | 主视觉画的是什么场景，全册如何裁切、改景别、调明暗复用 | "每页配一张图" |
| 禁止项 | 本项目明确不要的元素（用户已否定的方向、易混淆的装饰） | 留空 |

### 风格样张：两页，渲染后再看

锁定必须由**实际渲染的两页**确认，不能只凭提示词或单张插画：

1. **封面样张**：主视觉＋课题牌，验证画法、色彩、标题性格。
2. **代表内页样张**：必须是带真实学习材料、任务与作答/结论结构的内页（品读页或练习页），按[版面底版](page-chassis.md)的版位与量化上限排好版，验证板面、正文字号、对比度、锚点立绘位置和元件语言。

只过封面不算锁定——封面好看但内页塌成"底色＋几行字＋一个人物"，正是整册最常见的失败模式。两页都通过后，把这两页登记为**本项目的风格锚点**，后续所有素材以它们为准；再出现风格漂移时回到锚点比对，不拿被否定的版本当参考。

用户已明确选定风格或沿用上一套时，仍要出代表内页样张确认版位与字号，但不必重新提风格方案。

## 三、素材清单（asset manifest）

G1通过后，从page-plan逐页登记素材需求，**先成清单再生图**。每项记录：

`id` · `role`（hero/scene/figure/object/diagram/plate/icon）· `pages`（使用页，可多页）· `render_as`（image/native/background）· `edit_scope`（可移动/可缩放/可替换/内部不可编辑）· `identity`（角色身份锚点，适用时）· `alpha`（是否需要真实透明）· `aspect`（输出比例）· `prompt_ref`（实际提示词位置）· `status`（待生成/候选中/已验收/已替代）

清单里同时标出**共享素材**与**页面专用素材**。共享素材优先：一件素材被三页用过，胜过三件只用一次的素材。

### 足量的下限

设成册页数为 P，复现角色数为 C，page-plan中标注 `render_as=image` 的图解需求数为 D：

```
最少生成素材数 N_min = 1(主视觉)
                     + 3 × C(每个复现角色至少3个姿态/情绪，主角至少4个)
                     + D(教学图示素材)
                     + T(板材与标题牌：能用原生形状做出的记0，需要纹理/笔触质感的按实际件数计，通常2)
                     + ceil(P / 3)(页面专用素材)
且 N_min ≥ P
```

例：P=10页、C=1个复现角色、D=2个教学图示、板材走纹理（T=2），则 N_min = 1+3+2+2+4 = 12。

**候选冗余**：每一类关键素材（主视觉、主角立绘、每个教学图示）各生成至少2个候选再择优；alpha、身份一致性、裁切不合格的候选不计入 N_min。

这条下限的作用是防止"可编辑模式只生成一张背景"。它不是把素材数当成绩：**清单里每一项都必须在成册里被实际用到**，组装完成后清点未使用项，有未使用项就说明清单当时没想清楚，删除或说明原因，不塞进页面凑数。

### 不允许的素材策略

- 每页一张整页图，再在上面盖原生文字框——这是整图模式，不是可编辑模式。
- 同一个提示词随机跑多次凑数量；不同素材写不同提示词。
- 把八页缩略拼在一张图里当"全套素材"。
- 用程序绘制的几何占位图替代需要的插画。

## 四、批量生成的组织

1. **先锚点后批量**：主视觉与主角立绘先各出一件，经验收成为后续批次的身份/画法参考，再按角色、按页型分批跑。
2. **同批共享提示词骨架**：一批内固定风格段、色彩段、输出段，只换主体段，用[动态提示词](prompt-templates.md)的模板填充。骨架一致是全册画法一致的保障。
3. **按角色成组跑姿态**：同一角色的3—4个姿态放在同一批，便于比对身份一致性（脸型、服装、配色、年龄感）。
4. **逐批验收再开下一批**：一批出完立刻按第五节检查，不等全部跑完再回头返工。
5. **并发与重试**：次数与并发度以宿主限制为准，不把某平台的参数套给另一个工具；同一问题两次定向修正仍失败，改素材方案或改布局，并在交付说明中写明。

## 五、素材逐项验收

| 检查项 | 判据 | 不通过的处理 |
|---|---|---|
| 主体完整 | 四周留白8%—12%，头、手、道具无裁切 | 重生成或改构图 |
| 身份一致 | 同一角色跨姿态的脸型、发型、服装、配色一致 | 带身份参考重生成；无参考输入时在提示词里复述已固定的身份特征 |
| 画法一致 | 与风格锚点对照线条、上色、材质、色彩组织 | 回锚点改写提示词，不拿被否定版当参考 |
| 透明真实 | 有alpha需求的素材放到深、浅两种底色各看一次，查发丝、手部、白色衣物与道具边缘 | 按[生图方法](image-generation.md)的透明三条路线处理；不能抠图时改用同底色插画块并如实说明 |
| 无夹带文字 | 素材内不含文字、数字、标签、Logo、水印 | 重生成；不靠裁切遮挡 |
| 分辨率 | 放到成册实际尺寸后不糊；底图层素材长边不低于成册画布长边 | 重生成 |
| 教学准确 | 图示的结构、数量、关系、状态经核实 | 改为原生图解或重生成 |

**精确关系不交给生图**：数据、刻度、箭头关系、公式、表格、拼音与答案用原生对象，不烘焙进插画。生图负责氛围、场景、角色与难以原生绘制的具象物。

## 六、G2 门禁

进入组装前逐条确认：

1. 清单内每一项 `status=已验收`，且有可访问的实际文件。
2. 生成总数达到 N_min；未达到时说明是哪一类不需要、为什么。
3. 每个复现角色至少3个姿态，主角至少4个。
4. 主视觉已产出其全册裁切/明暗派生方案（派生由排版完成，不必逐张生图）。
5. 需要透明的素材全部通过深浅底检查。
6. 风格锚点两页仍是当前画法的准绳，未被中途漂移取代。

未通过不进入组装。确因宿主能力不足无法通过，按第七节如实降级，不把"提示词已写好"当作素材已完成。

## 七、生图能力不足时的降级

| 情况 | 做法 |
|---|---|
| 完全无生图 | 交付page-plan、style-spec、素材清单与逐项提示词；明确"素材未生成"。有用户已提供且适用的素材时可继续组装 |
| 能生图但无透明/抠图 | 改用同画布底色的插画块或无重叠布局，如实说明背景仍在 |
| 能生图但无参考图输入 | 在每条提示词里复述已固定的身份与画法特征，说明细节一致性较弱；不假称已传图 |
| 能生图但无演示文稿能力 | 交付素材＋准确文案＋组装计划，说明"可编辑PPT尚未生成" |

任何降级都写进交付说明，列明实际交付物与缺失项。不声称已生成未生成的文件，不猜测未公开的底层模型名。

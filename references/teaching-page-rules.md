# 教学用PPT页面规则

本文件规定本Skill制作课堂课件时的默认页面规则，适用于整页图片、可编辑PPT及两者同时交付。先遵守当前用户明确要求，再采用这些规则；参考课件中的具体课题、措辞、人物、配色与装饰不因此成为永久模板。

本文件管**页面的教学语义**；页面的版面骨架、版位数值与逐项可数的量化上限在[版面底版与页面量化约束](page-chassis.md)，两份同时执行。凡本文件写"不能挤""不能缩字""密度与任务相称"之处，以page-chassis.md中的具体数值为准。

## 一页一个教学动作

每张教学内页只承载学生此刻的一项主要操作，并能说明即时产出或可观察表现。先写清“学生做什么、用什么材料、做到什么程度”，再决定页数和版面。

- 动作按学习操作与产出判定，不机械地按动词数量判定。“读准并读连贯”可属于一次朗读表现；“朗读、圈画、讨论”若分别产生朗读表现、圈画结果和讨论结论，就应拆页。
- 一个动作可以延续多页：材料过长、需要分段或逐步展开时，保持同一动作，分成连续页面；不能为固定页数把多个动作合并。
- 一页可以包含完成该动作所必需的材料、提示、图解与操作空间，这些内容必须共同服务同一产出。
- 材料页、朗读页、观察页本身可以承载教学动作，不必额外加一组问题与答案。答案、点拨和结论按课堂推进需要另页或逐步展示，不默认每页同时出现。
- 封面用于建立课题与学习期待，不强加可检查的练习产出；不能借封面例外合并多个内页教学环节。

| 情形 | 处理 |
|---|---|
| 一页要求学生“朗读一段材料”，材料与朗读提示共同支持一次朗读 | 保留一页；即时表现可为按要求完成朗读 |
| 一页要求“读一读、圈关键词、与同伴讨论、写结论” | 按独立产出拆成连续页面 |
| 一个观察图附有必要标签，学生据此说出一个关系 | 可作为同一观察动作；标签不是额外任务 |
| 为控制在8页，把观察、归纳与练习挤在一页 | 按动作增页，重新安排节奏 |

## 从教学设计到学生上屏文案

文案遵循教学设计中实际发生的课堂讲述和活动顺序，不能先做版式再填通用教学口号。每页保留一条可追溯链：**教学设计中的课堂讲述/活动 → 本页教学动作 → 学生上屏材料与提示 → 教师备注**。

1. 先提取当前教学设计中的教师讲述、追问、示范、学生任务、使用材料及预期表现，核对课文、题目、数据等准确内容。
2. 把讲述改写成适合学生当场理解的自然口语提示。保留任务对象、操作要求和必要条件，不堆砌“探究一、合作交流、能力提升”等抽象环节名称。
3. 学生屏幕呈现完成该动作所需的原文、题目、图表、示例、简短提示和必要支架。原文、引文、题目条件不能为追求短句而失真；长材料可以连续分页。
4. 教师的长篇讲解、过渡话、追问预案、教学目标、设计意图、评价方式和组织方法放在备注或独立教学说明中；不把“培养思维能力”“体会语言魅力”等教案表述当成学生正文。

用户未提供教学设计时，先依据任务、教材与已核实资料形成“教学设计工作底稿”，明确其为本次拟定，再从底稿生成页面。不得宣称用户已经提供或确认该设计。已有完整设计时按教学动作推导页数；既无设计也无页数要求时，8页含封面只是启动估计，规划后可增页。

| 教案或讲述内容 | 学生上屏 | 教师备注 |
|---|---|---|
| “请大家默读这段文字，找出最能体现人物心情的一处，稍后说说理由。” | 对应文字；“默读，找出最能体现人物心情的一处。” | 提请学生交流理由的时机与追问预案；交流若产生独立产出，另页承接 |
| “通过比较，培养学生分析与归纳能力。” | 先补足可执行的比较任务、准确材料和预期产出，不能原句上屏 | 目标与设计意图 |
| 较长的教师示范讲解 | 必要的示例、关系或简短步骤，按动作分步呈现 | 完整课堂讲述与示范要点 |

朗读分工提示（领读、接读、齐读、自由读、分角色读）和作答形式提示属于学生当场要执行的任务提示，可以上屏；它们不属于副标题，也不因“只保留课文原句与必要出处”而被删除。

## 全册单栏纵向内容流

“单栏纵向”指**在当前画布内，学生阅读与操作所需内容沿一条从上到下的主线排列**。默认仍为16:9横版，不改成竖屏，也不把中文旋转或排成逐字竖列。

- 每页允许0或1个主标题；有标题时，标题在上，主要学习材料和任务相关提示依次向下组织。没有标题时可直接进入材料或任务。
- 全册不使用左右图文分栏、左右双栏、侧栏导航、多卡片网格或多个并行任务区；不同页可以改变材料尺度、插画范围、留白和层次，但不能改变单一内容流。
- 插画、照片、图表可占据内容流中的一段，相关正文放在其上方或下方。背景和边角装饰不承担第二条阅读任务，也不能挤占主要材料。
- 为表达关系所必需的对照图、数学图、示意图和表格可以保留内部空间关系，整体作为一个学习材料嵌入单栏。它们不能借此变成两个独立的“题目+解释+任务”分区。
- 同一材料内部的标签、必要图注、表头和操作标记按意义就近放置；它们不构成侧栏或第二内容流。
- 内容放不下时先删除冗余讲述和装饰，再按动作或材料自然边界增页；不能缩成小字、改成双栏或合并不同任务。

## 全册统一版面底版

"单栏纵向"约束阅读顺序，"统一底版"约束每页长什么样。两者缺一，整册就会变成一页一个样的拼贴。底版的层职责、版位数值与页型库见[版面底版与页面量化约束](page-chassis.md)，此处只列必须执行的部分：

- **五层固定**：底图层（全幅主视觉及其裁切/明暗派生，不承载任何文字）→ 内容板层（承载全部正文的单一主板，每页至多1块）→ 内容层（标题、材料、提示、图解、作答支架）→ 锚点层（角色立绘或关键道具）→ 标注层（圈画、下划线、气泡、箭头）。层职责不混用。
- **正文阅读区**：复杂底图必须加内容板，纯色阅读区不强制可见边框；不把正文直接压在未经可读性处理的复杂底图上；正文与其直接背景的对比度≥7:1。
- **锚点立绘不进入阅读流**：不承载信息、不加标签、不与正文构成图文对照、不压字。它是视觉落点，不是第二栏。
- **同页型版位固定**：同一页型的主板四边位置在全册内偏差≤1%。
- **页型只用七种**：封面、任务分段页、材料页、品读页、组织页、练习页、小结页。新增页型须在页面计划中登记版位与呈现步。

## 版面量化上限

下列数值逐页可数，验收时必须给出实际值。完整表见[版面底版](page-chassis.md)第三节。

| 维度 | 限值 |
|---|---|
| 正文字号 | ≥画布高4.5%（16:9标准页≈24pt），推荐5%—7% |
| 主标题字号 | 7%—10%画布高；内页不得用封面式巨字 |
| 单页正文行数／每行汉字 | ≤12行／≤26字 |
| 单页上屏汉字 | 常规页≤180字；整段材料页≤320字且该页只放这一份材料 |
| 视觉语义组 | 通常≤12；底层原生组件数另记，表格、关系图、笔顺和拼音部件不得为减数合成图片 |
| 字族／字号层级／语义色 | ≤2族／全册≤3级且单页≤3种／全册≤4色且单页≤3色 |
| 标注类型／聚焦遮罩 | 每页≤2类／每页≤1处且可退回全景 |
| 常驻装饰带／非教学装饰总面积 | ≤25%画布高／≤画布面积25% |

**总则：先拆页，不缩字。** 所有容量冲突都按教学动作与材料的自然边界增页解决，不靠缩字号、挤行距、开第二栏，也不把学生必需的材料搬进备注。

**颜色即语义**：颜色语义全册一致；首屏可显示任务与给定材料的必要强调，答案、结论和待学生发现的证据标记后置。按对象职责与任务判断泄题，不以颜色单独判定。

## 无副标题

全册每页只允许0或1个主标题，不加副标题、标题下的解释句、双层题头、眉题或装饰性环节名称。封面也遵守这一规则。

按功能判断文字，不按位置、字号或是否像句子判断：真正要求学生完成的提问、指令和任务提示属于正文，可以保留；不能为了“无副标题”删掉学生必需的任务，也不能把副标题改名为“提示”后继续占据第二层题头。

例如主标题“观察图形”下再放“发现图形的变化规律”作为概述，是副标题，应删除或并入主标题；“观察这组图形，说出下一幅的画法。”若是本页实际任务，就是正文，应与材料按单栏顺序组织。

**二级标题的判定**：标题下以字号、颜色或装饰区分的说明句、导语条、环节名、栏目条与固定提示行，都属于二级标题，应删除或并入正文；学生要执行的完整任务句属于正文，不因位置靠上而降级为副标题。除教材原文、必要图注、来源标注和活动要求的“AI生成”标注外，正文页不设小字说明行。

## 无页眉、页脚、页码

全册不出现页眉、页脚、页码、进度编号、顶部或底部固定导航、品牌条、Logo、水印、固定课次和教师信息。检查范围包括普通页面对象、幻灯片母版、版式、隐藏对象及已烘焙到背景或整页图片中的文字与标识，不能只关闭自动页码就算完成。

教材出处、课次、教师信息、制作信息等放在备注、资料记录或独立说明文件中，不作为屏幕装饰。正文理解所必需的作者名、作品名、计量单位、图注、引用标记或题目自身编号可以保留；必要学术/素材署名依其实际要求安排，不能把正文标注误当页脚，也不能虚构出处。素材来源与“AI生成”等制作标注默认放备注或独立说明；确因活动规则要求上屏时，用统一且极小的固定形式，不视为页脚，也不得每页重复堆叠。

**课题页的教材信息例外**：教材版本、学段册次、单元、课号与课题名可集中显示在课题页一处，作为教材身份信息；它不是页眉页脚，也不构成副标题，但只出现这一次，正文页不得重复。教材信息须与所用教材逐项核对，不能确认的版本或册次标为待核实，不猜测；课次、页码与出处仍放备注或相关材料。

## 课题页与教材信息

课题页是全册唯一显示教材身份的位置，建议集中呈现教材版本、学段册次、单元、课号与课题名：可用一行或两行文字加一枚课号徽标，与课题组成一个整体，不堆单元导语、学习目标或教师信息。

- 教材信息只出现一次；正文页不重复版本、单元与课号。
- 版本、册次、单元、课号、课题名逐项核对；不确定的项标为待核实，不猜测。
- 课号徽标与教材信息只承担身份识别，不承担教学动作，也不作为每页页眉。

## 正文页的字级层级：一个大标题加一块大内容

正文页只保留一个主标题和一块主内容。主内容可以是课文原句、题目、任务句、对比材料或图解，但同页只有一块主要阅读区，不再切出第二层题头或小字说明。

- 标题下不加解释性副标题、导语条、环节名、栏目条；这类内容即使字号很小、换了名称，仍按二级标题处理。
- 除教材原文、必要图注、来源标注与活动要求的“AI生成”标注外，不设小字说明行；教师追问、预设回答、设计意图、评价语与知识点补充放备注。
- 学生要执行的任务以完整指令句呈现，字号与主材料同级或接近，可做成整幅任务条；任务条写学生要做的动作，不加“任务一”“环节二”等编号与环节名。
- 一页放不下时按教学动作拆页，不缩字号、不增加小字行。主材料与任务句执行[版面底版](page-chassis.md)的字号下限：≥画布高4.5%（960×540pt页约24pt），并检查实际投影可读性。
- 课题页可用大标题与整幅场景；正文页的标题、材料与任务保持同一套层级，不把封面式海报延续为内页。

## 图片优先使用教材原图

需要图片时，按“教材原图—配套官方资源—生成图或网络图”的顺序选择。

- 教材原图包括课文插图、单元导语页、教材页面扫描或拍摄图、课后题图等；使用前核对册次、单元、页码，避免拿错版本。
- 教材原图按原比例嵌入，不拉伸、不裁掉图文关系；放大局部时用独立裁切图，并保留原图与出处。
- 教材页面扫描图用于呈现教材原貌（课文页、课后题、批注示例）时可保留图中文字；若页面文字需要编辑、放大或重排，则以原生文本重建，不用扫描图冒充可编辑正文。
- 不生成教材中已有的插图、人物形象或页面版式来替代原图；生成图只补教材没有的情境，并按活动或平台要求标注。
- 教材原图的册次、页码、单元等出处放备注或相关材料，不在页面上堆小字；版权与使用范围按课堂与活动要求处理。

## 额外提示用原生气泡与标注

需要在页面上补充提示、追问、批注或反馈时，优先使用PowerPoint原生的气泡与标注形状：圆角矩形、椭圆、对话气泡、标注（callout）、手绘圈注、下划线与箭头。它们必须是独立原生对象，可移动、可改字、可删除。image模式没有原生对象，气泡只能作为画面的一部分，交付时说明文字不可编辑；editable-ppt与both必须使用原生形状。

- 气泡承载“额外提示”，不承担本页主任务；主任务仍以大字号正文呈现。
- 每页气泡与标注合计不超过2个，全册语义统一：例如提问用对话气泡、强调用圈注、答案用另一种颜色；不压字、不遮作答区、不覆盖教材原图的关键信息。
- 首屏不显示答案类气泡；提示与反馈按课堂讲述顺序后置出现，并与层级动画的击次对应。
- 不把气泡、圈注烘焙进背景或整页图片，不用图片冒充可编辑标注。
- 参考课件中的对话框与卡片可借鉴组织方式，不照搬其配色、头像、品牌与固定位置。

## 内容呈现的对应约束

按[内容呈现](content-presentation.md)记录material_id、材料范围、聚焦问题、学生产出、反馈依据与首屏。精读页给任务所需完整片段，不把全文小字缩入每页；比较只改必要差异；原生关系图可保留内部横向关系；学习方法后用新材料做同类练习。详情与反例见[六套参考学习记录](reference-study.md)。

## 常见页面类型的编排

| 页面类型 | 编排 |
|---|---|
| 课题页 | 教材信息＋课号徽标＋课题＋整幅场景；教材信息只出现一次，不堆目标与教师信息 |
| 材料/引文页 | 一个大标题＋一整块教材原文或材料；材料一次给全，不逐句遮盖 |
| 任务/练习页 | 一个大标题＋大字任务句或整幅任务条＋作答空间；教师追问与答案在备注 |
| 对比页 | 一个大标题＋上下两块材料；不用左右双栏，不用小字注解代替比较 |
| 收束页 | 一个大标题＋一句大字问题或一个回望任务；不设“谢谢观看”类装置 |

- 页面类型按教学动作选择，不要求全册套用固定几种；同一动作可以连续多页。
- 内页不复制课题页的巨型标题与满屏场景；材料页与任务页的可读内容占画面主要区域。
- 任务条、气泡、箭头、圈注都必须是原生对象，并与层级动画配合；不用整页图片冒充。

## 页面特效与呈现顺序

页面特效按[页面特效与呈现要求](page-effects.md)执行；其中硬性部分与前述页面规则同等对待，不得以“参考课件也这样做”为由豁免：

- **层级动画优先**：editable-ppt与both默认为标题、背景之外的上屏元素加层级动画，按课堂讲述顺序分成2—4击、单击逐层出现，不一屏全显；封面与纯静态材料页可以不设动画，并在页面计划中说明理由。
- **首屏只出任务与材料**：首屏保留标题＋本页任务或首要材料；答案、结论、评价、归纳后置到后续击次。把未点击的首屏导出为图片检查，答案必须不可见，首屏也不能是空白页或只有标题。
- **材料一次给全**：纯材料页、整段朗读页、整段圈画页，材料首次出现即完整，不逐句遮盖、逐行揭示。
- **点击驱动**：动画由教师点击推进，禁止自动定时连播；一步对应一次教师指令或一次学生反馈；每页2—4击，超过先检查是否该拆页；同一击可带出一个容器及其文字/标签（建议不超过3个对象）。
- **转场克制**：全册统一一种转场；使用平滑转场的前提是相邻页共享真实学习材料（同一课文句段、图解、任务框），共享环节栏头不构成理由。
- **标注可擦**：强调框、圈画、下划线、气泡批注是独立原生对象，全册统一语义、每页不超过2类，不压字、不遮挡作答区、不烘焙进图片。
- **不设导航与品牌装置**：目录页、导航条、进度条、抽象环节名牌（"情境导入""作者简介""能力提升"）、环节栏头、水印、版权页、关注页、谢谢观看页一律不做。确需分段时只用**任务分段页**：一条贯通横幅，幅内只写学生接下来要执行的真实任务动词短语（"找出描写环境的语句""聚焦言行，品人物形象"），不写抽象环节名（"情境导入""作者简介""能力提升"），不做导航条与进度条，全册≤3页。

## 制作与验收

- 页面计划逐页记录教学动作、即时产出、材料、教学设计对应讲述、准确上屏文案、教师备注、单栏阅读顺序和逐次呈现步；可编辑模式须把呈现步实现为**原生单击层级动画**（标题与背景常显，2—4击，逐层出现）。标题可以为空，不设副标题字段。
- 生图提示词、组装规格和母版使用相同规则。生成整页图片时明确禁止副标题、页眉页脚、页码和品牌条；独立素材不得夹带额外文字。
- 先核对内容与教学设计的对应关系，再检查实际渲染的整册页面；逐页导出首屏与每个击次末态，核对层级动画顺序、答案是否后置、是否一屏全显；自动检查可辅助发现对象和越界，不能代替识别图片内文字、阅读顺序与教学动作。
- 每页验收十一项：是否只有一个主要教学动作；文案是否来自真实课堂讲述；是否只有一条自上而下的内容流；**五层底版是否各就其位、同页型主板版位是否一致**；**[版面底版](page-chassis.md)第三节的每一行是否都能数出实际值并落在范围内**；**色彩语义是否与style-spec一致、首屏是否没有待发现标记、答案与结论**；是否没有副标题；是否没有任何形式的页眉、页脚和页码；是否每处动画都能说出对应的讲述或学生动作、首屏不见答案且不空白、层级动画逐击可操作；是否没有自动播放与定时翻页；是否没有目录、导航条、抽象环节名牌、环节栏头、水印等页面装置，任务分段页是否≤3页且写的是真实任务。任一不通过，先修正再交付。

## 案例校准：借鉴教学推进，不固定案例模板

此前案例记录使用《少年中国说（节选）（小语匠）》参考包（不是本轮六套参考），PPT共43页、16:9。以下页序按封面起算，用于解释规则，不作为后续课程的内容、画风或页数模板；包内docx只是预学单、43个备注页只有“微信公众号：小语匠”水印，**没有教学设计与课堂讲述**，不能假设参考包一定附带设计或备注。

- **教学推进**：第18—24页反复使用同一段材料，依次引导找词句、体会顺序、读节奏、比较用词、联系资料和再朗读。可迁移的是按课堂进程跨页推进，不是把所有动作合成一张“活动”汇总页；第19页还混有圈画、补图与背诵，新规则下仍需拆页。
- **呈现时机**：第20页先给问题、后出反馈；第10页拼音“先出字词→点击出拼音→再点击收起”的三态自查，是可迁移的检测型呈现。静态最后一帧不能当作开场屏，动画也不能成为同页放多个独立动作的理由。
- **页面特效**：43页全部使用2秒平滑（Morph）切换；42组相邻页里强接续6组、弱接续24组、无共享12组，可迁移的强接续是第19→20页语势图整套保留、只换问题并追加答案，第27—31页同一原文框“同框换字”，第37→38页同一照片放大位移。全册173个动画步、84个点击步、168进入/5退出/0强调；没有定时翻页，但有26组“进入页即自动播放”，其中第4、6、18、37、38页内容页进场后自动播完；13页无点击步、9页≥4步、最多8步（第36页），第26页一次点击连播7个对象达3秒。可迁移的是“统一切换＋共享真材料＋点击可控”，不可学的是“每页套转场却不接续内容”与“多步动画代替拆页”。
- **标注与装置**：标注全为原生可编辑形状、可与原文分离，值得保留；但语汇混乱——红色虚线框仅2处（第14、15页同一对象跨页）、蓝虚线8处承载4种语义、深红实线框5处、红圈画框16个（第26页7个、第32页9个）、气泡7个承载5种语义、手写自由形42个、荧光笔高亮仅第23页4处；第15页单页混用5类，第7/14/26/32/36页各3类。包装装置共11页：封面、目录（第2页）、6个报站页（第3、8、16、17、25、33页）、作业装置（第38—40页）、谢谢观看（第41页）、版权（第42页）、关注（第43页）；另有顶部栏目名11页、章节横幅17页。
- **版式与内容**：按单栏标准仅19/43页合格、24页不合格（含左图右文、左右并列、卡片阵列、图文拼贴）；底部整幅插图带占画面高43.1%、出现在20页，第14页压在正文之上；内页出现66/96/115pt封面式巨型标题（第3/8/16/17/25/33/41页）；第14、21页朗读材料晚于朗读要求出现；第24、37页仍有教学效果表述上屏；第26、32页课文错字（“一泻江洋”“商商皇皇”）仍被长期上屏，强调框不得把错字框成重点。
- **证据与限制**：上述来自原生文字、形状坐标、动画时序与素材图；当时该环境未成功打开含图片的演示文稿，**未做放映与渲染验收**。不推断参考存在所有被禁止的元素，不将品牌或推广带入新课件。

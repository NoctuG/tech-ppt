# 版面底版与页面量化约束

本文件把"全册单栏纵向、无副标题、无页眉页脚页码"从口头原则变成**可测量、可逐页打钩的版面约束**。适用于image、editable-ppt与both。与[教学页面规则](teaching-page-rules.md)、[页面特效与呈现要求](page-effects.md)同时执行；用户当前明确要求优先，但放宽任何一项都必须在交付说明中写明放宽了哪条、为什么。

约束一律用**画布百分比**表达，与比例无关；括号内为16:9标准页（PowerPoint宽屏960pt×540pt）的近似换算，仅供对照，不是另一套标准。

## 一、五层底版：全册同一套骨架

每页按固定叠放顺序组织，层职责不混用。不是每页都要有全部五层，但出现的层必须落在本层职责内。

| z序 | 层 | 职责 | 硬约束 |
|---|---|---|---|
| 1 | **底图层** | 全幅主视觉或其裁切/调明暗的派生图，提供全册统一环境 | 不承载任何文字、标签、答案；不得是纯色填充冒充"有设计"；正文不得直接压在未加板的底图上 |
| 2 | **内容板层** | 承载全部正文的单一板面（纸、卡、框或浅色块） | 每页**至多1块主板**；主板四边位置全册固定（见第二节）；板内不得烘焙文字 |
| 3 | **内容层** | 主标题、材料、任务提示、图解、作答支架 | 板内唯一一条自上而下阅读流；原生文本/形状优先 |
| 4 | **锚点层** | 抠底角色立绘或关键道具，作为视觉落点 | **不进入阅读流**：不承载信息、不加标签、不与正文构成图文对照，不压字 |
| 5 | **标注层** | 圈画框、下划线、气泡、箭头 | 独立原生对象、可擦；每页≤2类，语义全册一致 |

底图层贯穿全册是**成套感的主要来源**：同一张主视觉用不同裁切、景别和明度反复出现，比每页换一张新插图更统一，也更省素材。改变的是裁切与明暗，不是画面内容。

## 二、版位：全册固定，不逐页重排

| 区位 | 纵向范围（占H） | 横向范围（占W） | 约束 |
|---|---|---|---|
| 安全区 | 上下各留≥5% | 左右各留≥4% | 所有文字、作答区、标注在安全区内；立绘可出界但不得被裁掉头手 |
| 标题带 | 0%—16% | 居中或左起≥6% | 至多1个主标题；无标题时此带留空或由材料上移占用，不得补副标题、环节名、栏头 |
| 主板 | 上边6%—14%，下边82%—94% | 左右各内缩3%—6%，板宽88%—94% | **全册同一页型的主板四边偏差≤1%**；板内文字再内缩≥2.5%W |
| 正文流 | 标题带以下至主板下沿之间 | 板内 | 一条自上而下的流；禁左右双栏、侧栏、并排任务卡、卡片阵列 |
| 锚点区 | 任意，但必须落在主板的四角或右缘一带 | 宽≤18%W | 高≤45%H；可部分压在板上、可出血到板外，但与最近字的净距≥1.5%W；每页≤2件 |
| 底图可见带 | — | — | 主板之外至少一侧露出底图≥2%，使环境感连续 |

**主标题通常落在主板顶部**（标题带与主板上沿重叠），也可以像任务分段页那样独立成一条压在底图上的横幅；两种之中每册只固定选一种做法，不逐页切换。

**单页至多1块主板。** 结论条、小标签底、答题框等副容器可以存在，但合计面积≤主板的35%，且全部落在主板内或紧贴主板，不另起第二阅读流。

## 三、量化上限：逐页可数

| 维度 | 上限／下限 | 超限处理 |
|---|---|---|
| 主标题 | 0或1个 | 删除第二层题头，或并入主标题 |
| 正文字号 | ≥4.5%H（≈24pt），推荐5%—7%（≈28—38pt） | 先拆页，不缩字 |
| 主标题字号 | 7%—10%H（≈38—54pt）；内页不得用封面式巨字 | 内页标题超10%H视为海报化 |
| 注释/标签/拼音字号 | ≥3.5%H（≈19pt） | 删注释或拆页 |
| 字号层级 | 全册≤3级；单页≤3种字号 | 归并层级 |
| 字族 | 全册≤2族（标题族＋正文族） | 归并 |
| 语义色 | 全册≤4色（底色、正文墨色、主色、强调色）；单页同时出现≤3色 | 归并配色 |
| 正文行数 | 单页≤12行 | 拆页 |
| 每行汉字 | ≤26字 | 加大行宽或拆行，不缩字 |
| 单页上屏汉字 | 常规页≤180字；整段材料页≤320字且该页只放这一份材料 | 按材料自然边界续页 |
| 原生对象总数 | ≤12（文本框≤5、图片≤4、形状≤6） | 合并装饰或拆页 |
| 标注类型 | 每页≤2类 | 归并标注语汇 |
| 聚焦／遮罩 | 每页≤1处且可退回全景 | 删除 |
| 常驻装饰带高度 | ≤25%H（底部插图带、花边等） | 缩小或改为底图层 |
| 非教学装饰总面积 | ≤画布25% | 删减 |
| 正文与其直接背景对比度 | ≥7:1 | 加板、提高板不透明度或换正文色 |
| 板面与底图明度差 | ΔL*≥35 | 压暗底图或提高板明度 |
| 文字墨量 | 板内文字覆盖≤板面积45% | 拆页 |

"先拆页，不缩字"是本表的总则：所有容量冲突都按教学动作与材料的自然边界增页解决，不靠缩字号、挤行距、开第二栏或搬进备注外的角落。

## 四、颜色即语义：全册一张对照表

每个项目在style-spec里固定下表，全册不变。颜色承担语义，不随页面情绪换色。

| 语义 | 典型用法 | 要求 |
|---|---|---|
| 正文墨色 | 课文原文、题干、材料 | 最高对比度；原文永远用这一色，不被强调色替换 |
| 主色 | 主标题、任务提示、标签底、图解框线 | 一个色族，深浅不超过2阶 |
| 强调色 | 学生答案、结论、圈画框、关键词 | 只用于"后一击才出现"的内容，首屏不得出现 |
| 底色 | 板面、结论条底 | 低饱和，不与正文抢对比 |

**强调色即答案色**：用颜色也能看出哪些内容必须后置。首屏截图里出现强调色文字，等于答案提前泄露，直接判不通过。

## 五、页型库：七种页，各有固定版位

全册只用下列页型；新增页型须在页面计划中登记其版位与呈现步，并同样遵守第二、三节。同一页型在全册内版位一致，这是"成套"的判据。

| 页型 | 构成 | 版位要点 | 默认呈现步 |
|---|---|---|---|
| **封面** | 全幅主视觉＋课题牌（＋课时标） | 可满幅、可大字；不设任务与练习；无副标题 | 不设动画 |
| **任务分段页** | 全幅主视觉＋一条贯通横幅 | 横幅高12%—18%H，内只写学生接下来要做的**任务动词短语** | 不设动画 |
| **材料页** | 主板＋一份完整材料 | 材料占板内≥70%；锚点立绘≤1件 | 材料一次给全；≤2击 |
| **品读页** | 主板＋一句/一段材料＋标注＋结论条 | 结论条贴板底，高≤15%H | 材料→标注→结论，3击 |
| **组织页** | 主板＋原生框线/箭头图解（流程、关系、分类、对比） | 图解整体是一个学习材料，内部空间关系可横向 | 骨架→节点→关系，2—4击 |
| **练习页** | 主板＋题干＋作答支架（横线、空格、格子） | 作答支架占板内≥30%，不被立绘遮挡 | 题干→（学生作答）→参考答案，2—3击 |
| **小结页** | 主板＋结论或练笔任务 | 单块文字，留白≥40%板面积 | ≤2击 |

**任务分段页的边界**：横幅内只能是学生要执行的真实任务（"聚焦言行，品人物形象""找出描写环境的语句"），不得是抽象环节名（"情境导入""作者简介""能力提升"）、不得是导航条或进度条、不得带栏头，全册**≤3页**。它不豁免[页面特效](page-effects.md)对目录页、导航条、进度条、抽象环节名牌、水印与品牌页的禁止。

## 六、进阶式复现：同一材料跨页加层

同一份材料连续出现2—3页，每次只加一层加工，是精品课件把教学讲清楚的主要手法，也是拆页的正当理由：

平铺材料 → 圈画/标注 → 归类或建立关系 → 得出结论

每一步是独立产出，因此是独立页，不是同一页的多步动画。相邻页共享的是**同一份真实材料对象**，这正好满足平滑转场的前提。判据：若相邻两页去掉标注后材料完全相同，则属于合法的进阶复现；若只是换了一句话、底板相同，则是凑页。

## 七、逐页自检（结构部分，可在无放映能力时完成）

1. 五层是否各就其位，底图层上是否没有文字，锚点立绘是否没有承载信息、没有压字。
2. 主板四边是否与同页型其他页一致（偏差≤1%）。
3. 是否只有一条自上而下的阅读流；图解内部的横向关系是否确属一个完整学习材料。
4. 第三节的每一行是否都能数出实际值并落在范围内；超限项是否已按"先拆页，不缩字"处理。
5. 色彩语义是否与style-spec一致；首屏是否不含强调色文字。
6. 页型是否在七种之内，任务分段页是否≤3页且写的是真实任务。
7. 标题带是否没有副标题、环节名、栏头；全页是否没有页眉、页脚、页码、品牌条、水印（含母版、版式与烘焙进底图的）。

任一不通过先修正再交付。结构自检不能代替[质量检查](quality.md)里的教学语义与渲染检查。

## 八、案例校准：《桥》（部编版六年级上册）课件

仅用于解释上述约束的来源，不作为后续课程的课题、画风、页数或配色模板。证据为该PDF 48页的逐页目视，**未获得其源文件，未做放映与动画验收**，因此不对其动画结构下结论。

**可迁移的做法**

- 全册48页共用同一张洪水主视觉：封面满幅、任务页横幅压幅、内页压暗后退到板后、尾页只留局部。素材总量很小，成套感却很强——这是"底图层贯穿全册"的直接依据。
- 所有正文落在同一块毛边纸板上，板的四边位置几乎不动；板外四周露出底图。文字对比度始终足够，底图再复杂也不干扰阅读。
- 老汉立绘有指、吼、揪、推、站等多个姿态，按页面语义换用，固定落在板的右上或右下角，从不压字、从不带标签——锚点层的范本。
- 颜色严格承担语义：墨黑=课文原文，赭棕=教师指令与标题标签，朱红=学生答案与圈画。只要看首屏有没有红字，就知道答案有没有提前出现。
- 元件词汇很窄且复用：笔刷标题牌、深色小标签（动作/对比/环境/人物）、贯通任务横幅、红色圈画框、填空横线、浅色结论条。七八个元件撑起全册。
- 进阶式复现用得彻底：词语平铺→按环境/人物归类；四处语言描写平铺→逐句品读（每句一页，配一个立绘姿态与一条结论）→回到四处汇总。
- 正文字号大、行数少、留白多；多数页只有4—12行字。

**不可迁移、本Skill仍禁止的做法**

- 第11页左侧材料、右侧流程图，第30页文字旁并列照片与插画，属左右双栏，违反单栏纵向。本Skill的处理是上下排列或按进阶式复现拆页。
- 第3页做成胶片造型的单元目录页，属目录装置，本Skill不做。
- 任务页的"任务一/二/三"写的是真实学习任务（"感受环境描写""聚焦言行·品老汉形象""读懂题目深意"），这是它与被禁止的"情境导入""能力提升"式环节名牌的区别；即便如此，本Skill仍限全册≤3页。
- 其课题、人物、水墨画风、赭棕配色、字体与具体版式都不是本Skill的默认值；下一个项目按[风格提取](visual-style.md)重新建立。

# 教学课件页面特效与呈现要求

本文件规定教学课件在**页面特效**层面的要求：切换（转场）、层级动画（逐次呈现）、强调标注、聚焦遮罩、图像质感、以及必须删除的页面装置。适用于image、editable-ppt与both的整册页面，与[教学用PPT页面规则](teaching-page-rules.md)同时执行；冲突时以用户当前明确要求为先。

特效不是装饰层，是**讲述的节奏**：每一处切换、动画、标注、蒙版都要能对应“教师此刻说什么、学生此刻做什么”。说不出来就删除。editable-ppt与both默认**给页面文字等元素加层级动画**——按课堂讲述顺序逐层单击出现，不一屏全显；标题与页面背景常显；全部出现后的最终状态仍是完整可读的教学页。image模式没有动画层，特效只能是单帧可见的静态手段。

## 一、转场：全册统一，且必须接续真内容

| 要求 | 判据 |
|---|---|
| 全册只用一种转场，时长克制（建议不超过2秒），不与教师讲述抢拍 | 幻灯片切换面板逐页同值；封面到内页、环节交界处也不炫技 |
| 使用平滑/Morph的前提是**相邻两页共享同一可见对象**，且该对象是学习材料本身（同一课文句段、同一图解、同一任务框、同一容器） | 相邻页能找到同位置或同内容的真实材料对象；否则改用简单切页 |
| 不得用转场表达讲述里没有的因果、递进、放大或“生长”；不得靠转场掩盖环节切换 | 逐对相邻页说明“哪段讲述需要这个接续”，说不出即删 |
| 相邻页共享的是环节名、栏头、水印等页面装置时，不构成使用Morph的理由 | 共享对象必须是学生要读/看的内容 |

## 二、层级动画：默认要求，单击逐层出现

- **默认给文字等元素加动画**：每页把标题与背景之外的上屏元素，按课堂讲述顺序分成2—4个击次，逐层出现，**不得一屏同时显示全部内容**；封面与纯静态材料页可以不设动画，并在页面计划中说明。
- **标题、页面背景、常驻装饰常显**，不参与动画；不要为每个气泡、每行标签单独设计动画。
- **单击触发（On Click）**：一步对应一次教师指令或一次学生反馈；禁止自动播放、随页自动播放、定时翻页与“进入页面即播完”。
- **首屏只出现“此刻要做什么”**：标题＋本页任务或首要材料；答案、结论、评价、归纳一律后置到后续击次，不能与问题同屏出现。未点击的首屏不能是空白页或只有标题的页面。
- **材料页一次给全**：纯材料页、整段朗读页、整段圈画页，材料首次出现即完整，禁止逐句遮盖、逐行揭示。
- **检测类可用三态**：拼音、生字、字词、背诵等自查，可用“先出题面→点击出答案核对→再点击收起”的显示—核对—隐藏结构。
- **每页2—4击为宜**；超过4步先检查是否该拆页或删提示，不得用多步动画代替拆页。一步对应一次教师指令或一次学生反馈。
- **一次点击只解一层**：一处点击可带出一个容器及其文字/标签，建议不超过3个对象、总时长不超过约1.5秒；把多个框或多个名称串在一次点击后，教师无法中途停，学生也跟不上。
- **层级顺序按教学逻辑**，不按版面位置：可以“材料先出、问题后出”“原文先出、改图建议后出”，但每一击都要能说出一句对应讲述。
- **反馈顺序服从课文或讲述顺序**，不按版面位置重排；逐项反馈时，标记与该项答案同时出现，不提前把全部标记摆满。
- **答案已经被学生说出的页码**，不再补动画重复一遍；同一动作的材料与反馈可以同页分步，但不得因此合并两个独立产出。

## 三、强调与标注：统一语汇，独立可擦

| 要求 | 判据 |
|---|---|
| 只用原生、可移动、可删除的标注对象：方框、下划线、自由曲线、气泡批注、箭头、虚线框 | 动画窗格/对象列表可见；教师能一键擦除，不留在背景或图片里 |
| 全册定义一套标注语义并沿用（例：红框=关键词或关键句；气泡=释义或追问；绿色线=停顿与节奏），**每页最多2类** | 逐页清点标注类型；同色同义、同形同用 |
| 不用高亮色块覆盖原文：荧光笔式整块高亮会压住字形与标点，确需底纹时只作可擦的浅色下划带。标注不压字、不跨行截断、不遮挡作答区 | 静态截图逐字检查可读性 |
| 标注不能烘焙进图片或背景图，不能用“已经画好红框的整页图”冒充标注 | 图片文件内部无标注像素 |
| 被强调的文字必须与教材、资料原文逐字一致，不得把错字框成重点 | 逐字核对（参考课件第26、32页有错字仍被上屏） |

## 四、聚焦与遮罩：一眼一处，可退回全景

- 局部放大、框选聚焦、暗角、半透明蒙版只在“本步只让学生看这一处”时使用，**一页最多1处**。
- 任何遮罩都必须随时可退出回到全景，不能靠复制多页实现“遮住—揭开”。
- 不得用永久蒙层把学习材料藏起来；不得对课文、史料、实物图、示意图本身做模糊、羽化、降低对比度的处理。
- 拼音、注释、答案用“后现＋可收起”，不用半透明永久蒙层。

## 五、图像与质感特效：统一风格，不糊材料

- 柔化边缘、圆形或异形裁切、描边、投影等用于统一人物器物造型与分层，不得削弱信息细节。
- 常驻装饰插图（如底部整幅插图带）不超过画面约三分之一；插图承担观察、看图说话等任务时可放大为主体，此时该页不再另加装饰。参考课件的底部插图带占画面高43.1%、出现在20页，其中一页压在正文之上，属于要避免的做法。
- 大圆、色块等背景装置可以作底色，但正文对比度必须够，且不得遮挡文字与作答区。
- 优先零阴影、零发光、零模糊；质感只用于需要分层或统一造型的图片（如人像柔化边缘）。参考课件全册无阴影、无发光、无模糊，仅3处柔化边缘。
- 同页进入方式建议不超过3种；材料与图片优先用轻量出现（出现、淡入、擦除），不用飞入、百叶窗、随机线条等花哨方式堆叠。
- 禁止旋转、弹跳、闪烁、发光漂移、3D翻转等与教学无关的动效。

## 六、不设页面装置（删除项）

以下装置不因参考课件出现而继承，无论静态还是做成动画层：

- 目录页、导航条、进度条、报站/任务过渡页、“任务一”“活动一”“环节二”式环节编号与名牌。
- 每页固定环节栏头（“情境导入”“作者简介”“读准字词”“初读课文”“写好生字”等）与重复的活动长题头。
- 水印、品牌组、版权声明页、扫码关注页、“谢谢观看”页。
- 页眉、页脚、页码、课次、教师信息（既有规则）。

环节分界由教学内容与备注承担；确需分隔时，用一页只承载学生任务与材料，全册不超过3页，且不写环节编号与环节名。

参考课件用11页（占25.6%）做目录、6个报站页、作业装置、版权、关注与谢谢观看，另有顶部栏目名11页、章节横幅17页；这些都是应删除的页数与视觉层，不能以“成套感”为理由保留。

## 七、多媒体（使用时）

音频、视频、录屏必须教师可控、不得自动播放，并有对应文本或字幕；不能用视频或GIF代替原生动画与原生文字。

## 八、可编辑与可维护

- 动画必须是原生动画（动画窗格中可见、可删、可改时序），转场可在切换面板修改；不得用视频、GIF或整页图片模拟。
- 标注、聚焦框、蒙版、遮罩都是独立原生对象并保留语义名称，便于教师擦除与复用。
- 教师备注承载完整课堂讲述、追问预案与预设回答；备注为空是缺陷，不得当作规范。
- image模式没有动画层：特效只能是单帧可见的静态手段（框线、圈画、标注、遮罩、焦点区），不得用多张连续图暗示逐句揭示，也不得让标注或色块遮挡文字。

## 九、验收（静态截图即可判定）

| 检查项 | 判据 | 不通过的处理 |
|---|---|---|
| 首屏可用 | 未点击首屏导出图为完整可用的教学页：标题＋本页任务或首要材料；不是空白页、不是只有标题 | 补首层材料或调整呈现结构 |
| 层级齐全 | 标题与背景之外的元素按讲述顺序分成2—4击逐层出现，不是一屏全显；每击对应一次教师指令或学生反馈 | 重新分层或拆页 |
| 答案不可见 | 首屏截图中答案、结论、评价均不出现；答案同屏靠动画藏住不算后置 | 改为后置到后续击次 |
| 材料完整 | 朗读页、圈画页、材料页中材料首次出现即完整，无逐句遮盖 | 取消逐句揭示 |
| 点击可控 | 逐页点击步数2—4，与page-plan的reveal_steps、课堂指令一一对应；一次点击连播对象≤3个且总时长≤约1.5秒；无定时翻页，内容页不进场自动播完 | 删步、拆页或改自动为点击 |
| 转场统一 | 全册同一种转场；使用Morph的相邻页确有共享学习材料 | 改简单切换或补接续对象 |
| 标注统一 | 每页标注类型≤2，全册语义一致；可单独删除 | 归并标注语汇 |
| 标注不遮挡 | 不压字、不遮作答区、不跨行截断，且未烘焙进图片 | 改位置或改原生对象 |
| 聚焦克制 | 每页聚焦/遮罩≤1处，且可退出全景 | 删除多余蒙层 |
| 装置清除 | 无目录、报站页、环节栏头、水印、版权页、关注页、谢谢观看页 | 删除 |
| 特效有理由 | 每处动画、标注、蒙版能说出对应讲述或学生动作 | 删除 |

## 十、案例校准：《少年中国说（节选）》（小语匠）

以下只用于解释规则，不作为后续课程的内容、画风、页数或特效模板。该包43页、16:9；证据来自逐页XML坐标、动画时序与31张素材目视，**未做放映与渲染验收**（本机PowerPoint无法打开含图片的演示文稿）。

- **转场**：43页全部为平滑（Morph，按对象），时长2秒；但42组相邻页里强接续仅6组、弱接续24组、无共享12组（第5→6、8→9、24→25、32→33、35→36、40→41等只是2秒交叉淡化）。真正可迁移的强接续是：第19→20页整套语势图保留、只换问题并追加答案；第27—31页同一原文框同坐标“同框换字”；第37→38页同一照片放大并位移。可学的是“统一切换＋共享材料”，不可学的是“每页都套Morph却不接续内容”。
- **逐次呈现**：全册173个动画步（168进入、5退出、0强调），其中84个点击步、89个随同或自动步；没有定时翻页，但存在26组“进入页即自动播放”，其中第4、6、18、37、38页进场后会自动播完，教师无法控制。时长以500毫秒为主（160个），另有1000毫秒（5个）与“出现”1毫秒（8个），延迟最长3秒，无重复、无路径动画。正例：第10页拼音“先出字词→点击出拼音→再点击收起”的两态自查；第19页逐词7次独立点击。反例：第26页一次点击连播7个红框、再一次连播7个名称（单步3秒，教师无法中途停）；第32页一次点击连播3个标签；第36页8步同时承载问题、关系图、结论与答案四项产出；第34页全页唯一动画是底部装饰带飞入，而“语调选择”始终没有答案呈现。
- **强调与标注**：标注全为原生可编辑形状，但语汇近十种混用——红色虚线框仅2处（第14、15页，且是同一对象跨页）、蓝虚线8处承载4种语义、深红实线框5处、红圈画框16个（第26页7个、第32页9个，压在原句上）、气泡7个承载5种语义、Freeform手写42个、荧光笔高亮4处仅在23页；第15页单页混用5类，第7、14、26、32、36页各3类。可保留的是“标注独立、可与原文分离、可擦”，不可学的是语义不统一与覆盖原文。
- **装饰与装置**：半透明深红圆罩（α22%）出现在15页；底部整幅插图带（占画面高43.1%）出现在20页，其中第14页的插图带压在正文之上；全册无阴影、无发光、无模糊，唯一质感是3处柔化边缘（第6、29页）。43页中11页（25.6%）是包装装置：封面、目录（第2页）、6个报站页（第3、8、16、17、25、33页）、作业装置（第38—40页）、谢谢观看（第41页）、版权（第42页）、关注（第43页）；此外顶部栏目名11页、章节横幅17页。
- **版式与内容**：按单栏标准，43页中仅19页合格、24页不合格（左图右文、左右并列、卡片阵列、图文拼贴），教学内容页约四分之三不是单栏——本套只能作反例校正，不能当作单栏范本。内页出现66/96/115pt封面式巨型标题（第3、8、16、17、25、33、41页），44pt与36pt两套“第二标题”交叠，单页最多5种字号。
- **资料状态**：包内docx只是预学单，43个备注页全部是“微信公众号：小语匠”水印，**没有教学设计与课堂讲述**；本套不能作为“讲述—呈现”对齐的正面样本，也不能假设参考包一定附带设计或备注。
- **资产与字体**：关键教学素材是亚运点火图、梁启超像、课本页、红日/龙虎/鹰/奇花/干将剑/水彩少年、田字格；纯装饰图大量存在；第23、37、38页把同一张1920×1280的“六边框拼版图”整张贴入三次，属于典型的不可编辑反例。字体是“宋楷正文＋手书标题”两族分工，可迁移的是分工关系，具体商用字体不写入通用要求。

## 十一、边界

- 默认要求层级动画（单击逐层、不一屏全显）；仅封面与纯静态材料页可以不加动画，并需在页面计划中说明理由。
- 不禁止标注、气泡、柔化边缘、插图带等装置本身；禁止的是没有教学理由的堆叠、遮挡与自动播放。
- 特效风格随本套视觉系统变化，不固定为某几种动画或某些颜色；层级动画优先用出现/淡入等轻量进入，不用飞入、百叶窗、随机线条等花哨方式。
- 参考课件中的课题、文案、错字、页数、环节名、品牌与水印都不成为模板；其中的双栏、栏目条、副标题也不因效果好看而豁免页面规则。

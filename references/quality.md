# 内容、视觉与编辑性共同验收

## 教学页面硬规则：先验收

对照[教学页面规则](teaching-page-rules.md)，先检查最终整册的以下项目；任一不通过先修正，再进入风格与编辑性验收。

| 检查项 | 验收证据与不通过的处理 |
|---|---|
| 一页一个教学动作 | 逐页能说明学生当下的动作、所用材料和即时产出；朗读、圈画、讨论等若有不同独立产出则拆页。多个点击动画不能代替拆页，同一动作的材料与反馈可依课堂顺序逐步呈现。封面不强加练习产出。 |
| 文案对应课堂讲述 | 对照page-plan的教学设计位置、classroom_wording、student_action和exact_text，检查任务对象、条件与提问次序；教师长讲述、追问预案、目标与设计意图在备注或独立说明。没有教学设计时依据明确标记的工作底稿，不能声称用户已提供或确认。 |
| 全册单栏纵向 | 查看全套缩略图与每页大图，材料和提示只有一条自上而下阅读流；无左右图文双栏、侧栏、并排任务卡或多任务网格。画布比例保持用户要求，未定时16:9横版；完整图解内部必要空间关系不误判为双栏。 |
| 无副标题 | 每页至多一个必要主标题，可无标题；封面也没有副标题、双层题头或固定环节条。按功能区分正文提问/指令，不能删掉真正任务，也不能把副标题改名提示而保留。 |
| 无页眉、页脚、页码 | 检查普通对象、实际启用的母版/版式元素、自动日期/编号和背景/整页图片中的烘焙文字。无常驻课名、课次、品牌导航与教师信息；正文必要作者、原文、单位、图注和题目自身编号按意义保留。 |
| 课题页教材信息 | 课题页显示版本、册次、单元、课号与课题且只出现一次，正文页不重复；各字段与教材一致，不能确认的标为待核实。 |
| 正文层级 | 每页只有一个主标题和一块主内容；标题下无二级标题、导语条、栏目条与多行小字；教师追问、预设答案与设计意图在备注。 |
| 教材原图 | 用图页优先教材原图，比例未拉伸、图文关系完整、册次页码与出处可追溯；未生成教材已有插图替代原图。 |
| 气泡提示 | 额外提示为原生可删除的气泡或标注，每页合计≤2个，未压字、未遮作答区；首屏无答案类气泡。 |

区分检查能力：check_editability.py与finalizer只证明其报告列出的对象、边界或包结构，不能证明教学动作唯一、讲述吻合、无图片内副标题或单栏语义成立。母版有未启用页脚占位符不等于实际放映违规，结合可见性、继承与渲染判断；没有实际放映验证时只报告已检查范围。

## 版面底版与量化约束：逐页给出实际值

对照[版面底版与页面量化约束](page-chassis.md)，本节的每一项都要**数出实际值**再判断，不凭印象。无放映能力时本节仍可完整执行。

| 检查项 | 验收证据与不通过的处理 |
|---|---|
| 五层各就其位 | 底图层上没有文字、标签或答案；正文位于清楚的阅读区，复杂底图已加内容板，纯色阅读区可无可见边框；锚点立绘不承载信息、不加标签、不压字。违反者改层或删除 |
| 页型与版位 | 每页的page_type在七种之内；同一页型的主板四边位置在全册偏差≤1%。偏差超限时对齐到该页型的标准版位 |
| 字号与行数 | 逐页记录正文字号占画布高的百分比（≥4.5%）、主标题百分比（7%—10%）、正文行数（≤12）、每行汉字（≤26）。超限**先拆页，不缩字** |
| 文字量 | 常规页上屏汉字≤180；整段材料页≤320且该页只放这一份材料。超限按材料自然边界续页 |
| 对象与层级 | 视觉语义组通常≤12，底层原生组件数另报；表格、关系图、字词/拼音或笔顺部件不因数量转成图片；字族≤2；全册字号层级≤3且单页≤3种。超限合并装饰或拆页 |
| 色彩语义 | 全册语义色≤4、单页≤3；正文墨色、主色、强调色的职责与style-spec一致且中途未换。不一致时统一回style-spec |
| 首屏不泄题 | 按对象语义检查：待学生发现的标记、答案和结论不可见；给定材料的必要强调可以先显示，不以颜色单独判断 |
| 对比度与明度差 | 正文与其直接背景对比度≥7:1；板面与底图明度差ΔL*≥35。不足时加板、提高板不透明度或压暗底图 |
| 装饰占比 | 常驻装饰带≤25%画布高；非教学装饰总面积≤画布25%。超限缩小或改为底图层 |
| 任务分段页 | 全册≤3页；幅内是学生要执行的真实任务动词短语，不是"情境导入""能力提升"式环节名，不带栏头、导航条或进度条。不合格者改写或删页 |

## 素材清单与流程门禁

对照[素材流水线](asset-pipeline.md)核对制作流是否按序执行，以及素材是否真的做了、真的用上了。

| 检查项 | 验收证据与不通过的处理 |
|---|---|
| G1已通过 | style-spec的七个字段都有具体值（含色值与底图策略）；封面样张与**代表内页样张**都已实际渲染并通过。只过封面不算锁定，补内页样张后重走后续阶段 |
| 风格锚点未漂移 | 成册页面与两张锚点样张比对线条、上色、色彩组织、板面与元件语言；中途换画法的页回锚点重做 |
| G2已通过 | 素材清单每项status=已验收且有可访问文件；必要槽位与必需生成项均100%覆盖；独立动作、场景与物件匹配页意；核对真实调用记录，不以复制文件、裁切派生或提示词充数 |
| 素材全部用上 | 清点清单中pages为空或实际未出现在成册的项。有未使用项就删除或说明原因，不为凑数塞进页面 |
| 复用优先 | 统计共享素材的复用页数。按项目底图策略检查共享与专用素材是否各司其职；同风格场景组可使用不同图，不能单凭复用次数判画风不统一 |
| 未走整页图捷径 | editable-ppt中不存在"整页图＋盖原生文字框"的页。发现即按素材清单重新拆层 |
| 透明真实 | 有alpha需求的素材在深、浅两种底色上各检查一次发丝、手部、白色衣物与道具边缘。不合格时重生成或改用同底色插画块并如实说明 |
| 素材无夹带 | 素材内无文字、数字、标签、Logo、水印。靠裁切遮挡不算通过 |

生图能力不足导致的降级按[素材流水线](asset-pipeline.md)第七节如实写入交付说明，列明实际交付物与缺失项。

## 页面特效与呈现：首屏与逐击验收

对照[页面特效与呈现要求](page-effects.md)，在放映状态下逐页检查：把每页未点击的首屏导出为图片，再逐击到末态各导出一次；同时核对动画窗格中的步数、对象与触发方式。

| 检查项 | 验收证据与不通过的处理 |
|---|---|
| 首屏可用 | 首屏图本身是完整可用的教学页：标题＋本页任务或首要材料；空白页、只有标题、缺材料或缺任务，均视为不合格。 |
| 层级齐全 | 标题与背景之外的上屏元素按讲述顺序分成2—4击逐层出现，不是一屏全显；每击能对应一句教师指令或一次学生反馈。 |
| 答案不可见 | 首屏图中没有答案、结论、评价、归纳；同一页用原生进入动画隐藏反馈，且实际放映首屏确实不可见、逐击顺序符合任务，可算后置；末态导出不能证明首屏已泄题。 |
| 材料完整 | 朗读页、圈画页、材料页的材料首次出现即完整，无逐句遮盖。 |
| 点击可控 | 逐页点击步数2—4，与page-plan的reveal_steps、课堂指令一一对应；一次点击连播对象≤3个且总时长≤约1.5秒；无定时翻页，内容页不得进场自动播完；自动出现的对象不承载新信息。 |
| 转场统一 | 全册同一种转场且时长克制；使用平滑转场处，相邻页确有共享的学习材料而非环节栏头。 |
| 标注可擦且统一 | 标注为独立原生对象，可从页面删除；每页≤2类、全册语义一致；不压字、不遮作答区、未烘焙进图片。 |
| 聚焦克制 | 聚焦、蒙版、遮罩每页≤1处且可退出全景；未对课文、史料、实物图做模糊或降对比处理。 |
| 装置清除 | 无目录页、抽象环节名牌、环节栏头、水印、版权页、关注页、谢谢观看页；任务分段页≤3页且幅内是学生要执行的真实任务。 |
| 特效有理由 | 每处动画、标注、蒙版能对应一句讲述或一次学生动作；与教学无关的旋转、弹跳、闪烁、发光漂移视为不合格。 |

image模式下特效只能是静态画面的一部分（如画在页面上的框线与标注），不得用多张图暗示逐句揭示；editable-ppt中层级动画、转场、标注必须是原生、可编辑、可删除的，不能用视频、GIF或整页图片冒充。无法逐击放映验证时，至少完成首屏导出与动画对象/步骤的结构检查，并如实说明未做逐击放映。

## 内容呈现与来源清理

按[内容呈现](content-presentation.md)逐页核对任务、证据、产出与反馈依据。比较页只变必要差异；图解节点有证据对应，定性曲线不伪造数值；迁移练习使用刚学方法与同一评价依据。逐项检教材版本/课号、册次、原文、字形、拼音、引文与答案；发现参考不一致时回本次教材核对。

检查可见画面及隐藏/画布外对象中的占位文案、重复文本、品牌与水印残留；结构文本与实际可见缺陷分别记录。无逐击放映能力时不得声称首屏/每击全部通过。

## 内容与参考职责

逐页核对当前page-plan的文字、拼音、标点、数字、单位、答案、结构、年级适配和来源，不冒称未知教材版本对齐。只作风格的参考图中的文字、数字、人物身份、物品、场景与水印没有混入本次内容。

实际文件可访问、可解码/打开，数量和尺寸以输出为准。提示词、计划和工具成功状态不能替代成品检查。

## 风格与整套关系

对照当前参考与本项目style-spec检查造型、轮廓、上色、材质、色彩组织、标题、场景层次与组件语言；检查是否在项目中途无意改变画法。以当前风格为标准，不用固定作品、奶油配色、某种人物比例或媒介作通用评分尺。

保持同套共享的视觉系统和必要身份一致，布局与内容密度随教学任务变化。检查是否复刻参考的具体人物/场景/容器/位置组合，或只有改字改色。风格匹配与内容/构图独立同时成立。

## 课堂可用性

逐页查看学生能否依据本页材料完成明确的读、看、想、说、写、比较或操作任务。教学材料不能只是风景上的一句配文；教学活动不能仅靠页面标题暗示。任务、问题和回答支架须具体匹配目标，而非每页机械堆叠。

区分封面、教学内页与用户另要的宣传概览。检查内页是否仍用封面式巨型标题、满屏风景、巨大吉祥物挤占正文；是否只有一条结论和一幅装饰画。出现这些情况时重做内页信息层级与课堂任务，不能只缩小同一张海报。原始卡通风格仍可保留。

检查正文、题干和必要图解能否用于投影阅读，字级/行距、背景对比、标注与作答区域是否清楚。任务需要时留圈画、比较、表达或练习空间；image模式可以静态展示这些区域，不因此免除教学要求。

## 视觉完成度

检查封面与代表内页是否完成page-direction.md的设计：主焦点、阅读顺序、场景/图解、人物动作、内容容器、层次和必要装饰相互配合。阅读区清楚，字体够大，装饰不遮挡。

可编辑版不能因拆分而退化成重复的底色、几行字与单个人物。丰富度从设计关系、层次与材质获得，不用无关素材堆数；清爽练习页也应有清楚的视觉组织。若参考的丰富感没有转化到实际PPT，回到页面设计和素材清单补齐，不只加一圈装饰。

查看实际主体、服装、手部、道具、裁切、透视、背景连接与清晰度，按本项目限制检查。不能仅凭无错字或某种装饰有无就判定视觉合格，也不替用户宣称一定更漂亮。

## image

每页独立完整、画幅一致、文案正确，必要教学图关系准确。全套缩略图用于概览，逐页大图核查细节。整图文字是像素；另生效果稿和正式交付明确区分。

## editable-ppt

对照元素清单核查实际编辑范围：文字/拼音/题目/答案为原生文本，精确图解为必要原生对象，需要单独移动的主体、道具和容器没有粘进背景，层级动画为原生动画（动画窗格可见、可删除、可改触发方式与顺序），独立位图内部仍不可编辑，非交互环境允许合并。

用当前宿主的可用方式验证修改标题、移动关键插画、修改必要图解、答案分离，以及动画的逐击触发与可删除性。不能用不可见文字覆盖整图伪造编辑性。透明素材检查真实alpha及深浅底边缘；带底图如实标注。

能渲染时从实际最终PPT逐页检查缺字、换行、遮挡、边界、字体替换、拉伸与层次。另生成的漂亮整图不能作为PPT视觉完成度证据。结构检查可验证基础对象，不能代替渲染或原生应用检查；缺什么验证就说明范围。

## both

文稿和导出图片的内容、页数与版本一致，优先从最终文稿渲染。另生艺术效果稿必须标记。部分能力缺失时分别说明完成与未完成。

## 交付与分享

交付用户要求的模式及必要项目材料，不包含凭据、缓存与日志。不在可复用Skill中固定本轮的教学文案、角色、配色、情境或原始参考图；这些仅保存在项目。模型只报告已知且实际调用的名称。

相对资源链接有效，文件可访问；没有在某软件中实际运行，就不标称实测兼容。检查命名与包顶层目录一致，项目样例不充当通用模板。

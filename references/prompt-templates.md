# 按任务动态组织提示词

模板只提供字段和参考职责，不是固定内容。每次填入当前任务、page-plan、style-spec、素材清单与最新意见。实际提示词只保存在项目中；不要把当前课题、例题、角色或配色反写成Skill默认值。删除不适用字段，不把占位符直接交给生图工具。

先读[教学页面规则](teaching-page-rules.md)。每次整页调用都明确一个教学动作、文案依据、全册单栏纵向、无副标题、无页眉页脚页码。独立素材不塞入教师讲稿，背景为连续单栏留白；以下策划字段不逐字作为画面文字生成。

## 参考职责说明

```text
图片{编号}仅作风格参考：观察{本项目选定的线条、造型、上色、材质、色彩组织、标题与空间层次}。
参考图中的文字、数字、公式、教材信息、Logo、水印、人物身份、场景和物品均不是本次内容。不复刻其具体布局或装饰组合。
本次主体、文字、关系与布局以下列任务为准：{当前项目要求}。
```

仅在真实传图时使用图片编号。若另有本项目身份参考，明确其职责和要保持的特征；不能把风格图自动升级为角色身份图。工具不支持参考输入时，改为可观察特征的文字描述，不假称已传图。

## 批量骨架：一批内只换主体段

按[素材流水线](asset-pipeline.md)分批跑素材时，一批共享同一套**风格段、色彩段、输出段**，只替换主体段。骨架一致是全册画法一致的保障，也便于比对同一角色跨姿态的身份。

```text
【风格段·本批固定】{style-spec的造型、线条粗细与轻重、上色方式、材质、有无体积与投影}
【色彩段·本批固定】{底色、正文墨色、主色、强调色的具体色值与明度关系}；不在素材内使用强调色作为装饰
【主体段·逐项替换】{本项素材的身份、姿态、视角、状态、道具}
【输出段·本批固定】比例{比例}；四周留白8%—12%，主体完整不裁切；{透明/纯底/同画布底色}；不生成文字、数字、标签、Logo、水印
```

一批内每项仍各写各的主体段，不用同一条提示词随机跑多次凑数量。

## 0. 风格样张（G1锁定用）

锁定风格需要封面和代表内页两张实际样张。image模式可按D生成；editable-ppt/both用A/B/C所需少量候选与原生文字图解试排后看实际渲染。生图效果稿须单独标记，不能冒充原生PPT渲染。加入下面的验证要求。

```text
本图用于确认本项目视觉系统，不是最终页面。
样张类型：{封面 / 代表内页（必须带真实学习材料、任务与结论或作答结构）}。
需要在图中验证的事：{板面形态与边缘处理 / 正文字号与行距在投影下的可读性 / 正文与背景的对比度 / 锚点立绘的位置与不压字 / 标题牌与小标签的形状语言 / 色彩语义分工}。
版位：按本项目底版——底图层{主视觉及其明暗处理}，内容板{四边内缩比例}，正文落在板上，锚点立绘贴{板的外角/右缘}且不压字。
不要：封面式巨型标题用于内页；满屏风景挤占材料；副标题、页眉、页脚、页码、环节栏头。
```

代表内页样张不能用封面代替：封面验证不到板面、字号、对比度与元件语言，而这几项正是整册成败所在。

调用前核对asset_id及它满足的visual_slots，明确是G1少量候选还是G2批量素材。没有真实图片文件与验收记录，提示词不算完成。

## A. 底图层／无字背景/场景层

```text
用途：{当前课题/项目}的{全册底图层主视觉 / 第N页专用场景层}，输出比例{比例}，用于可编辑PPT。
复用要求（主视觉时）：这张图要以不同裁切、景别和明暗贯穿全册，因此画面{四周/上下}留出可裁切余量，构图在{满幅、横向带状、局部特写}三种取景下都成立；主要信息不集中在正中，避开内容板覆盖区{板的四边位置}。
风格：{本项目style-spec的具体画法、色彩组织与场景层次}。
视觉概念与环境：{本页教学目的对应的场景}。
布局：预留从上到下连续的单栏主阅读区，{文字、图解和独立主体上下衔接的位置与比例}；景物分布在{不打断内容流的位置}，前中后景按{层次关系}设计。不得预画左右双栏、侧栏或并排任务卡。
分层：这张只含{允许合并的非交互景物}；不含{另行生成的教学主体、人物、道具、容器或图解}。
文字：不生成文字、数字、公式、标签、Logo或水印，不预置副标题牌、页眉、页脚、页码或导航条。准确文案由PPT原生对象添加。
输出：{整页无字底图/独立场景块}；背景与透明需求为{实际需求及工具可用方案}，不能画棋盘格假透明。
```

## B. 独立人物/道具/物件

```text
用途：{当前项目}第{页/多页}页的独立{对象类型}，后期单独置入PPT。
风格：{本项目选定的具体画法与色彩关系}。
主体身份与结构：{本项目新设计或用户明确指定的身份、外观、服装/材质、形状和必要结构}。
本次姿态/视角/状态：{服务本页任务的具体动作与道具关系}。
身份参考（实际可用时）：{编号及职责}；保持{已建立的本项目身份特征}，改变{本次动作/视角/状态}。
分离要求：{哪些对象必须分别移动，哪些属于不可分的一组}。
构图：主体完整、四周留裁切安全空间，{方向、比例与视角}，适合放在{页面位置}。
背景：{真实透明/适合抠图的纯底/同画布底色的插画块}，按工具实际能力选择。
排除：本页不需要的第二主体、场景、文字、标签、Logo和水印；其他限制为{当前项目禁止项}。
```

需要多个不同对象或姿态时分别写提示词。需要分别移动的人物和道具不要无意合并；天然相连的一组对象可以合成一张，但明确编辑边界。

## C. 教学场景/关系插画

```text
用途：{当前学科/年级/课题}中的{本页知识关系或观察任务}。
画法：{本项目style-spec}。
内容与结构：{核实后的对象、数量、结构、状态与动作}。
布局：{准确空间关系、观察视角和标签留白位置}；作为单栏中的一个完整学习材料，不另设侧边讲解栏。图解内部保留教学所需的空间关系。
教学准确性：{本页必须成立的关系与易错点}。
编辑安排：{需要独立生成的对象}；原生制作{文字、公式、刻度、箭头、数据或必要图解}，不把它们烘焙进插画。
限制：{本页容易生成的具体错误和不需要内容}，不添加Logo或水印。
```

复杂精确结构优先原生对象或可核实素材；不靠生图承担可编辑的精确数学和数据关系。

## D. 完整整页图片

```text
用途：{当前项目}第{页}页完整教学图，{比例}，只输出这一页。
参考职责：{实际输入图片的风格/项目身份职责；不可用时改为文字画法}。
页面职责：{封面/教学内页/用户另要的宣传概览}，不得混淆。
本页目的：{具体目标}。
教学设计依据与当下讲述（不生成在画面上）：{设计位置；教师此刻说的话；无设计时标记工作底稿}。
材料身份与范围：{material_id、material_range，引用保持准确}。
本页唯一教学动作与即时产出：{学生此刻做什么，怎样看出完成}；学习材料：{准确材料与必要操作空间}。
呈现时机：{初始可见的材料/问题；完成后才出现的标记/答案，静态整图用后续页承接}。
课堂排版：保持{用户画布比例，默认16:9横版}，单栏纵向，从上到下排列{可选唯一主标题、材料、必要提示或作答支架}，按课堂实际顺序选择，不固定套满全部组件。无左右图文双栏、侧栏或并排任务卡。教学内页不沿用封面式巨字、满屏风景和装饰密度；图示因教学观察需要放大时明确说明。
视觉概念：{人物/场景/主体怎样帮助理解内容}。
布局与层次：{主焦点、文字区、图解区、前中后景、容器与必要装饰的关系}。
准确文字清单：{逐项列出本页实际文案、必要拼音/数字/公式和标点}。
风格系统：{本项目造型、线条、上色、材质、主辅色职责、标题与正文处理}。
保持：{本套已确定的画法与角色身份（需要时）}；本页变化：{任务对应的构图、动作和主体}。
限制：只生成准确文字清单，无副标题、页眉、页脚、页码或固定环节条；不额外加拼音、题目、标语、教材信息、署名、Logo或水印。教师讲述、设计意图、预设答案只作创作依据，未列入本页准确清单的文字不上屏。不复制参考内容与具体布局，文字无截断、遮挡或无意重叠。
```

整图文字融入像素，不自动恢复为PPT图层。不要把独立素材模板当作整页设计，或只交一张全套缩略拼图。

## E. 定向编辑

```text
图片{编号}是编辑目标，{其他参考编号与实际职责（如有）}。
只改变：{一个明确问题或一组必要关联改动}。
必须保持：{现有文字、人物身份、构图、配色、场景、比例等具体不变项}。
新准确文字（涉及改字时）：{正确内容}。
输出新版本，无额外文字、水印或无关改动。
```

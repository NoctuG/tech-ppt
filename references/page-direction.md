# 逐页设计与元素拆解

可编辑卡通课件需要先设计每页，再决定哪些内容用原生对象、哪些内容生图。基础PPT构建器和现成形状只能执行设计，不能替代场景策划。整图模式也使用页面设计单；只有可编辑模式需要进一步安排可移动素材。

全程执行[教学用PPT页面规则](teaching-page-rules.md)：一页一个教学动作；文案从教学设计的课堂讲述转成学生上屏材料；全册在用户指定画布（未定时16:9横版）内采用单栏纵向内容流；每页0或1个主标题，无副标题、页眉、页脚和页码。

版面不是逐页自由发挥：每页先从[版面底版](page-chassis.md)的**七种页型**中选定一种（封面、任务分段页、材料页、品读页、组织页、练习页、小结页），该页型的版位、默认呈现步和量化上限随之确定；设计工作是在这套骨架内安排内容与层次，不是重新发明版式。同一页型在全册内版位一致，这是"成套"的判据。

## 先谋划整套

根据当前教学设计与课堂讲述设计教学路径、情境或主线、页面类型与密度节奏。先为每页确定学生动作、材料和即时产出，再决定视觉方案。独立产出不同的朗读、圈画、讨论等活动拆页，同一动作可因材料长度延续多页；不为固定页数合并动作。没有教学设计时先形成明确标记的工作底稿，再据此设计，不能声称其来自用户。

明确这套课件怎样吸引注意、讲清关系、引导操作和完成练习。主线可以是叙事情境，也可以是问题探究或知识结构，不强加某个固定故事或环境。页面不必都做成“问题+答案”：朗读材料、观察图和示范材料本身可承担当下任务。

建立视觉系统后安排封面、代表内页与关键复杂页。先验证能代表本套难度的页面；只做好封面不能证明后续图解、练习与信息排版同样成立。

## 封面与教学内页分开设计

封面负责建立课题、情境与学习期待；内页负责让学生读材料、观察、比较、表达或练习。封面和内页均不设副标题、页眉、页脚和页码。内页主标题可省略，保留时仅一个且不压过教学正文/核心图解；主标题下不再加概述性第二层题头。真正的提问、任务指令属于正文，不能误删。完整情境图可用于看图、叙事或观察任务；精读、归纳、计算和练习页应为材料与操作空间让位，不用整页风景填满。

画风一致与版式职责不同可以同时成立。保留本套的造型、笔触、色彩关系和必要角色；逐页调整标题比例、插画面积、材料组织与背景复杂度。封面可作画法参考，不能默认作为内页版式参考；若内页连续海报化，停止沿用封面作唯一图像参考，建立通过验收的教学内页样板。

根据课堂投影与该页任务确定字级、行距和留白；内页主标题不应压过需要学生阅读的材料。参考起点可为标题约占高度8%—12%、主要学习材料与活动占可用区域约60%以上，但不把比例当所有课型的硬模板。观察图本身就是学习材料时允许放大主体；其余装饰缩到边角或减少。

每页写清“学生此刻做什么”和“凭什么材料完成”。保留需要的圈画区、比较区、书写/口述支架或答案揭示边界；不需要纸笔的页不强加空格。内容有适合投影的容量，不用扩大装饰弥补教学材料不足。

## 单栏纵向组织

在用户指定画布内（比例未定时默认16:9横版）建立唯一的自上而下内容流，例如“主标题（可无）→任务提示→学习材料→必要操作空间”；顺序服从本页实际教学，不强迫每页包含全部区段。中文保持正常横排。

- 文字、插画、图表按内容先后上下组织，不排成左右图文、左右双栏、侧栏或多卡片任务网格。
- 必要的对照图、数学图、示意图与表格作为一个学习材料整体放入内容流；其内部标签、线条、表头与空间关系按知识本身安排，不能拆成两个独立任务区。
- 场景层次、边角装饰与原生对象的叠放不等于第二栏；这些元素不能承担另一套并行任务，也不能形成固定导航或品牌条。
- 容量不足时删减重复讲述和装饰，或按动作、材料自然边界增页。不能缩字、挤成双栏或把教师讲稿全部搬上屏。
- 出处、课次、教师和制作信息放备注或独立说明；正文理解必需的作者、单位、图注等按意义保留。课题页例外：教材版本、册次、单元、课号与课题名可在课题页集中显示一次，正文页不重复。

## 每页的设计单

在page-plan中记录：

- title（可为空）、page_type、purpose、student_action、immediate_output：本页至多一个主标题，页型取自[版面底版](page-chassis.md)第五节的七种之一，学生只承担一个主要教学动作，并记录其即时产出或可观察表现；不设副标题字段。
- textbook_info：仅课题页填写的教材身份信息（版本、册次、单元、课号、课题名）及其核实来源；其余页留空，正文页不重复。
- teaching_design_source、classroom_wording、learning_material、exact_text、speaker_notes、sources：教学设计对应段落/环节、课堂实际讲述、本页使用材料、准确上屏文案、教师备注和资料来源。上屏文案是学生所需的材料与口语任务提示；长讲述、目标、设计意图和组织方法进入备注。
- material_id、material_range、focus_question、student_product、feedback_basis、first_view、visual_slots：材料身份与范围、当下问题、学生产出、反馈所据证据、首屏对象及逐页素材需求，按[内容呈现](content-presentation.md)填写。
- visual_concept、focal_point：本页怎样通过画面支持教学，第一眼看哪里，视线如何进入正文/图解。
- layout：单一内容流中各段材料、关系图或操作空间的上下顺序、比例、位置与留白；必要学习材料内部的空间关系单独说明，不能借此增加第二内容流。
- layers：按[版面底版](page-chassis.md)的五层登记——底图层、内容板层、内容层、锚点层、标注层。不是每页都要有全部五层，但出现的层必须落在本层职责内：底图层不承载文字，锚点立绘不进入阅读流、不承载信息、不压字。
- interaction / reveal_steps：教师需要修改、移动、替换、逐步展示或留作答空间的对象。按[页面特效与呈现要求](page-effects.md)列出呈现步：每步出现什么、由哪句讲述触发、对应哪次学生动作；标题与背景常显，首屏只出本页任务或首要材料，答案与结论后置。可编辑模式默认按讲述顺序安排2—4击、逐层出现；封面与纯静态材料页可不设动画并在计划中说明，不为动效硬拆动作。
- assets：需要的新素材、可复用的本项目素材、教材原图（课文插图、教材页面图、课后题图，记录册次与页码）、原生对象及其职责；额外提示注明气泡或标注形状与语义。

自然场景页、对话页、实物观察页、知识组织页与计算/实验页可以调整材料尺度、场景层次与留白，但都保持单栏纵向内容流。相同任务可以复用组件，换教学目的时重新确定动作与材料，不能只改一段文字。

## 编辑性决定拆分粒度

| 对象职责 | 推荐实现 | 拆分边界 |
|---|---|---|
| 环境、远景、无交互的氛围 | 一张无字背景或少数场景层 | 允许合并非教学装饰，记录其内部不可编辑 |
| 需要指认、比较、移动或替换的主体 | 独立插画/实物图、原生形状 | 不与背景或人物粘成整块 |
| 人物与关键道具 | 按教学用途单独素材，或必要的一组插画 | 需要分别移动的道具另生成；角色身份在本套固定 |
| 内容容器与标签 | 优先原生形状；复杂外观可用无字装饰底图 | 标题、正文始终叠放为原生文本，容器不能烘焙文字；不生成副标题、页眉页脚、页码或固定品牌导航 |
| 教材原图、教材页面图 | 独立嵌入图片，保持原比例 | 需要编辑、放大或重排的文字用原生文本重建，不让扫描图替代正文 |
| 追问、批注、反馈气泡 | 原生圆角矩形、椭圆、对话气泡或标注 | 文字、位置、大小、颜色可改、可删除，不烘焙进背景 |
| 文案、数值、拼音、公式、答案 | 原生文本/公式等可编辑对象 | 保持准确字形与对齐，答案按呈现需要独立 |
| 数据、精确位置/关系、刻度和实验标注 | 原生表格/图表/线条/形状 | 用可检查的精确结构承载教学关系 |
| 小装饰、强调符号 | 主题一致的独立图标或原生对象，必要时并入背景 | 控制密度和遮挡，不为凑素材数生成无关元素 |

非交互装饰可以合并；需要操作的教学主体保留独立性。不能把整页合成背景、只叠几行字就当作完整设计。按教师实际编辑需要和教学关系决定粒度。

## 素材清单

字段、需求覆盖标准、批次组织与逐项验收表在[素材流水线](asset-pipeline.md)，此处只说它与页面设计的接口：设计单定下每页需要哪些素材，素材清单把它们汇总去重，共享素材与页面专用素材各有职责：背景、组件可复用，特定场景、动作、对象必须按页需求制作，不能只按复用次数评价质量。

每项记录id、role、pages、render_as（native/image/background）、edit_scope、source_or_prompt、placement/layer和所需输出比例；人物/物件另记identity与透明需求。字段可随宿主简化，不能省掉编辑范围。

区分本套共享素材与页面专用素材。先生成风格/身份锚点，再按页面设计生成不同姿态、视角、道具与场景；需要几项不同对象就分别写相应提示词，不能把一张整页图当作素材清单。组装完成后清点未使用项：有未使用项说明清单当时没想清楚，删除或说明原因，不塞进页面凑数。

## 用层次形成视觉完成度

让主场景、人物动作、标题造型、容器、图解和少量装饰共同服务焦点；通过前后层次、大小、对比和节奏组织画面。内容阅读区保持清晰、足够大，景物围绕信息布置。

排版后检查：是否有场景/教学视觉的设计，素材是否互相呼应，页面密度是否与任务相称。封面可以饱满，练习区域可以清爽；不要求每页堆满，也不把“可编辑”当作删减设计的理由。

## 实际文稿验证

先组装并渲染封面与代表内页。把最终PPT的实际渲染和本项目style-spec/当前参考比较，确认内容清楚、层次完整、插画不是孤立摆放，同时验证一页一个动作与单栏纵向规则，再扩展整套。检查全部页面、母版、版式及背景中的副标题、页边信息和编号；只关闭自动页码不能替代实际检查。另生的整图效果稿不能替代此检查。

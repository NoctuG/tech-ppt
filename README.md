# tech-ppt

成套卡通教学课件 Skill：按教学设计中的课堂讲述和当前参考风格，制作整页图片、可编辑 PPT 或两者。

Skill 本身不内置任何一套课件、课程文字、角色或配色——固定下来的是**制作流**与**页面约束**，内容与视觉方案每次由用户任务决定。

## 固定制作流

```
① 接单与模式  ② 教学底稿与拆页  ③ 风格锁定 ■G1■  ④ 素材批量生成 ■G2■
                                ⑤ 版面组装  ⑥ 层级动画与节奏  ⑦ 验收与交付
```

门禁不通过不得进入下一阶段。

- **G1 风格锁定** — style-spec 落到具体值（含色值与底图策略），并由两张**实际渲染**的样张确认：封面样张，加一张带真实学习材料、任务与结论/作答结构的代表内页样张。只过封面不算锁定。
- **G2 素材齐备** — 素材清单每项已验收且有可访问文件，必要槽位与必需生成项均100%覆盖，所需动作与场景均齐备，需要透明的素材通过深浅底检查。

**为页面批量调用生图模型是本 Skill 的核心能力**，整图与可编辑 PPT 两种模式都要走第 ④ 阶段。

## 固定页面约束

- **五层底版** — 底图层（主视觉及其裁切/明暗派生，不承载文字）→ 内容板层（每页至多 1 块主板，同页型版位全册固定）→ 内容层 → 锚点层（角色立绘，不进入阅读流、不压字）→ 标注层。
- **七种页型** — 封面、任务分段页、材料页、品读页、组织页、练习页、小结页。
- **量化上限逐页可数** — 正文字号 ≥ 画布高 4.5%、单页正文 ≤ 12 行、每行 ≤ 26 字、常规页上屏 ≤ 180 字、视觉语义组通常 ≤ 12（原生图解部件另计）、字族 ≤ 2、语义色 ≤ 4、每页标注 ≤ 2 类、常驻装饰带 ≤ 25% 画布高、正文对比度 ≥ 7:1。容量冲突一律**先拆页，不缩字**。
- **颜色即语义** — 颜色语义全册一致；首屏可显示任务与给定材料的必要强调，答案、结论和待学生发现的证据标记后置。按对象职责与任务判断泄题，不以颜色单独判定。
- **一页一个教学动作、单栏纵向、无副标题、无页眉页脚页码**。
- **页面特效只服务讲述** — 层级动画按讲述顺序逐层出现、单击触发、不一屏全显，答案后置，禁止自动连播。

## 目录结构

| 路径 | 内容 |
|---|---|
| `SKILL.md` | Skill 主文件：输出模式、固定制作流、页面硬规则、执行路线 |
| `references/content-presentation.md` | 任务、证据、产出、比较、关系图与迁移练习 |
| `references/reference-study.md` | 六套参考的页级证据与检查边界 |
| `references/workflow.md` | 七阶段制作流与每阶段的产出物、放行条件 |
| `references/teaching-page-rules.md` | 页面的教学语义规则 |
| `references/page-chassis.md` | 版面底版、版位数值、量化上限、页型库 |
| `references/asset-pipeline.md` | 风格锁定与素材批量生成的两道门禁 |
| `references/visual-style.md` | 从当前参考提取风格、style-spec 字段 |
| `references/page-direction.md` | 逐页设计单与元素拆解 |
| `references/image-generation.md` | 提示词组织、透明处理、单图核对 |
| `references/prompt-templates.md` | 批量骨架与各类素材的提示词模板 |
| `references/editable-ppt.md` | 可编辑文稿的对象约定与组装 |
| `references/page-effects.md` | 转场、层级动画、标注、聚焦与禁用装置 |
| `references/quality.md` | 分层验收 |
| `references/host-capabilities.md` | 按宿主实际能力执行与降级 |
| `references/codex-adapter.md` | 可选的 Codex 组装适配器 |
| `scripts/` | 可选辅助脚本（素材覆盖、编辑性检查、纯色去底、Codex 构建器） |

| `使用说明.md` | 面向使用者的中文说明与请求模板 |

## 使用

按当前软件支持的 Skill / 自定义指令方式导入，保留顶层目录名 `tech-ppt` 与上表的相对结构。软件只接受文本时，提供 `SKILL.md` 与所需 references，参考图通过该软件的附件方式输入。

请求模板见 [使用说明.md](使用说明.md)。

## 内容呈现与参考学习

按[内容呈现](references/content-presentation.md)建立任务、材料、学生产出与反馈的对应；比较只变关键差异，关系图保留原生编辑，练习复用所学方法。六套《桥》《盼》共234页的实际检查与证据边界见[参考学习记录](references/reference-study.md)。可选`scripts/check_asset_gate.py`核对素材文件与覆盖，不代替真实模型调用、图片检查或放映验收。
